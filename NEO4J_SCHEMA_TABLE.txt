SCHEMA OVERVIEW
================================================================================
Central Node:        Plant (main entity)

Level 1 (Direct Plant Attributes):
  - LocalName, BiologicalName, PlantPart, Region, SoilType, Preparation

Level 2 (Chemical & Properties):
  - ChemicalCompound → ConstituentClass
  - ChemicalCompound → CuringProperty
  - Plant → CuringProperty

Level 3 (Medical Applications):
  - Plant → Illness
  - CuringProperty → Illness
  - CuringProperty → Symptom
  - Illness → Symptom
  - Symptom → BodySystem
  - Illness → BodySystem
  - BodySystem → BodyParts


KEY RELATIONSHIP PATHS
================================================================================
Query Pattern 1: Plant → Illness
  Plant -[:TREATS_ILLNESS]-> Illness

Query Pattern 2: Plant → Compound → Property → Symptom
  Plant -[:CONTAINS_COMPOUND]-> ChemicalCompound -[:EXHIBITS_PROPERTY]-> 
  CuringProperty -[:ALLEVIATES_SYMPTOM]-> Symptom

Query Pattern 3: Plant → Property → Illness
  Plant -[:HAS_HEALING_PROPERTY]-> CuringProperty -[:HELPS_WITH]-> Illness

Query Pattern 4: Symptom → System
  Symptom -[:AFFECTS_SYSTEM]-> BodySystem
